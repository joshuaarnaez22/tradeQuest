# Vision

Build the **Duolingo + Chess.com + TradingView for Trading Education**.

Instead of teaching users through long videos and PDFs, users learn by solving interactive chart puzzles, replaying historical markets, completing campaigns, earning XP, and receiving AI-powered coaching.

The platform should reward **good trading decisions**, **discipline**, and **learning**, rather than encouraging risky behavior or gambling.

---

# Product Principles

- Learn by doing
- Gamification over passive learning
- Reward consistency instead of profit
- Personalized learning paths
- Historical data over simulated randomness
- Short daily practice sessions
- Community-driven competition
- AI-assisted coaching
